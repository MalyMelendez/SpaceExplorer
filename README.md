# SpaceExplorer
A java program that explores Nasa's Astro Picture of the day API
The user enters a date, and the program retrieves info from NASA, including the image title, date, explanation and image URL.
The goal is to create and interactive exploration while practicing java programming.

# Example URL
For the date May 14, 2025, the program uses the following API URL:
https://science.nasa.gov/wp-json/wp/v2/apod-basic/250514
